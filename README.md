A one-line roast of the smart fridge, written by a tiny Python program to
`/output/entry.txt`: the fridge texts about expiring milk like a snitch in
my own kitchen, ratting out my leftovers. A judge model compares the lines
two at a time on humour first and freshness second; the funniest one takes
the reward. No stock joke about a fridge ordering too much milk — the sting
here is the snitch in the kitchen.

## Run it

```sh
python3 main.py
```

The program writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`) and prints it. The line is a fixed string,
so every run produces byte-identical output. At 114 characters it sits
inside the gate's 1–160 character limit.
